## [Unreleased]

### Breaking changes

- **REPLACE mode ("Sostituisci")** removes every Copy Transforms constraint on
  the destination bone, including constraints created manually and not by the
  add-on. This destructive behavior is now protected two ways: removing manual
  constraints requires an explicit confirmation in the "Confirm constraint
  replacement" popup (the "Confirm manual removal" option is disabled by
  default — without it, manual constraints are never removed), and an automatic
  JSON backup is always written before any removal
  (`actd_replace_backup_<armature>_<timestamp>.json`, saved next to the `.blend`
  or in Blender's temp folder if the file is unsaved, using the same schema as
  the JSON export). If the backup cannot be written, the replacement is
  cancelled.

### Compatibility

- Declared compatibility: Blender 4.2+ (4.2 LTS, 4.3, 4.4, 5.0, 5.1) on both
  installation paths (legacy add-on and extension manifest).
- Officially tested: Blender 5.2 LTS only (full regression suite).

### Known issues

- Blender 4.2–5.1 are declared compatible but have not been verified with the
  full regression suite; the UI has been verified manually on Blender 5.2 only.
- The generated-constraint registry is an ID property on the armature object:
  deleting or renaming constraints manually outside the Maintenance panel can
  leave orphan entries (removable via "Clean registry").

## [1.1.5] - 2026-10-22

### Changed

- Documentation only: English and Italian READMEs and package texts (ZIP/RAR)
  aligned to the Blender 4.2+ compatibility matrix.
- In-addon "Info" popup text aligned: tested on Blender 5.2 LTS, declared
  compatible with Blender 4.2+.

### Fixed

- Removed a broken link to `SPEC.md` from the documentation.

### Notes

- No functional changes to the add-on code.

## [1.1.4] - 2026-10-22

### Changed

- `bl_info` minimum version aligned to Blender 4.2+, matching the extension manifest.

### Added

- Animated demo GIF in the README.

## [1.1.3] - 2026-10-22

### Changed

- Simplified panel: the add-on presets are now a dropdown menu and rarely used
  controls moved to the **Advanced** section.
- Clearer UI labels, no longer truncated in the sidebar.

### Notes

- **REPLACE** removes all Copy Transforms constraints on the armature, including
  constraints created manually and not by the add-on.
- Quality: 538/538 checks passed on Blender 5.2 (11 suites, zero failures).

## [1.1.2] - 2026-10-22

### Changed

- Simplified UI: the most used settings (bone presets, tokens, mapping rules,
  replacement) are grouped into a preset dropdown menu.
- Rarely used options (filters, exclusions, cleanup options, technical details)
  moved to the **Avanzate / Advanced** panel, shrinking the main panel.
- Clearer field labels in both Italian and English.

### Notes

- **REPLACE** removes every Copy Transforms constraint on the armature,
  including the ones not generated by the add-on.
- Quality: 538/538 checks passed on Blender 5.2.

## [1.1.1] - 2026-10-21

### Changed

- Default tokens: `DEF_` for sources and `MCH_` for destinations.
- Fully bilingual IT/EN interface, following Blender's interface language.
- UI labels reorganized and no longer truncated in the sidebar.

### Added

- Per-panel diagnostic report: each panel shows its own report, with a separate
  **Advanced** panel.

### Notes

- Quality: 539/539 checks passed on Blender 5.2 LTS.

## [1.1.0] - 2026-10-21

### Changed

- Default tokens are now `DEF_` / `MCH_`; tokens with `-` remain supported.
- Cleaner main panel: quick start, numbered sections and readable fields.
- Clearer README, screenshots and release checklist.

### Added

- Bilingual UI: Italian and English, following Blender's interface language.

### Notes

- Tested on Blender 5.2 LTS: 389/389 checks passed.
- AI disclosure: developed with AI assistance, under the author's direction and review.
